ACCESSIBILITY

Accessibility statement

CHROME is designed so that everyone — including people using screen readers, keyboard navigation, or reduced-motion settings — can learn about our services and book a wash.

WCAG 2.1 AA target Keyboard navigable Screen reader tested Reduced motion supported Zoom-friendly to 200%

Our commitment

This site aims to conform to WCAG 2.1 at Level AA. Accessibility is treated as a gate — not a nice-to-have — because a car wash that can only be booked by some people is broken.

What we've done

  • Semantic structure. Every page uses <main>, <nav>, <header>, <footer>, and a single <h1>.
  • Skip link. Keyboard users can jump straight to the main content.
  • Contrast. All interactive text passes AA. The WhatsApp CTA uses dark-on-gold for a contrast ratio of ~8.6:1.
  • Focus states. Every interactive element shows a visible focus ring with a dark underlay, so focus stays visible on light and dark surfaces alike.
  • Keyboard support. Mobile menu, FAQ accordion, gallery filters, theme toggle, and lightbox are all operable without a mouse. Escape closes overlays. The lightbox traps focus while open and restores it on close.
  • Screen reader labels. Buttons, icon-only controls, and form inputs all have accessible names. Decorative icons carry aria-hidden.
  • Form design. Inputs are always labelled (not placeholder-only), use semantic types (tel, name), and set autocomplete where relevant.
  • Motion. The site respects prefers-reduced-motion. Animations are subtle and never necessary to understand content.
  • Responsive. The layout remains usable from 320px upwards and when zoomed to 200%.
  • Theme. A manual light/dark toggle is available in the header, independent of OS preference, and syncs the browser theme-color.
  • Language. Swahili phrases are tagged with lang="sw" so screen readers switch pronunciation correctly.

How this site was tested

  • Contrast ratios checked with browser dev tools and the WebAIM contrast checker.
  • Automated scan with axe DevTools.
  • Manual keyboard walkthrough of every page — tab order, focus visibility, Escape handling.
  • Screen reader pass with VoiceOver (Safari, macOS) and TalkBack (Android).
  • Layout verified at 320px, 375px, 768px, 1024px, 1440px widths, and at 200% browser zoom.

Known limitations

  • The embedded Google Map is a third-party iframe and its accessibility is outside our control. A textual address is always provided alongside it.
  • Placeholder photography is sourced from Unsplash. Alt text is descriptive but describes the photo, not the specific service shown — this will be replaced with the studio's own images.
  • The booking flow persists "last booking" in localStorage. Screen reader users are notified of the "Book again" option via a labelled button, but the persistence is silent by default.
